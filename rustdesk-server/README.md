# Home Assistant App: RustDesk Server

Self-host your own [RustDesk][rustdesk] ID and relay server directly on Home
Assistant. Runs **RustDesk Server 1.1.16**.

![Supports amd64][amd64-shield]

See the **Documentation** tab for setup.
